# 🧮 Calculadora

Calculadora web desenvolvida com HTML, CSS e JavaScript, criada para praticar lógica de programação e conceitos de desenvolvimento web.

## 🚀 Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- % Operação de resto
- 🔢 Números decimais
- ⌫ Apagar números
- 🧹 Limpar cálculo
- 🔄 Operações em sequência
- ⌨️ Suporte ao teclado do computador
- 📱 Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de colocar em prática conhecimentos de JavaScript, principalmente lógica de programação, manipulação do DOM e utilização de eventos.

## 💻 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando o navegador ou a extensão Live Server.
